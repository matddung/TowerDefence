# TowerDefence

### Unreal Engine 4.27 기반의 C++ 중심 타워 디펜스 게임
### 데이터 테이블 기반 웨이브 시스템과 스플라인 경로 AI를 구현한 전략 게임

## 프로젝트 개요
- **장르** : 타워 디펜스
- **목표** : 웨이브로 몰려오는 적을 처치하여 본진(타워) 체력을 지키는 전략 게임
- **플랫폼** : Unreal Engine 기반 PC 게임

## 프로젝트 기간
- 2025.06 ~ 2025.07

## 사용 엔진 버전
- Unreal Engine **4.27**

## 주요 기능 / 시스템
- **웨이브 시스템** : 데이터 테이블(`EnemyWaveData`)을 기반으로 적 스폰 수/간격, 체력, 이동 속도, 공격 주기 등을 설정하고 라운드를 진행
- **경제 시스템** : 골드 소비/획득, 웨이브 클리어 보상, 타워 건설 비용 관리
- **타워 배치/업그레이드/판매** : 타워 건설 미리보기와 배치 가능 영역 판정, 업그레이드/판매 UI 제공
- **타워 종류** : 기본 공격 타워, 스플래시 타워, CC(슬로우) 타워

## 캐릭터 컨트롤
- 캐릭터 이동 대신 **마우스 기반 컨트롤**을 사용
    - 좌클릭 : 타워 배치 확정/선택 해제
    - 우클릭 : 타워 선택/메뉴 토글, 배치 취소
- 배치 중에는 프리뷰 타워가 커서를 따라 이동하며, 충돌/경로 인접 여부로 배치 가능 여부를 표시

## 전투 / AI
- **적 AI** : 스플라인 경로를 따라 이동 후 본진에 도달하면 일정 주기로 공격
- **전투 로직** :
    - 타워는 일정 시간마다 가장 가까운 적을 탐색하고 공격
    - CC 타워는 적에게 슬로우를 부여
- **피드백** : 적 체력바 UI 및 피해 숫자 플로팅 텍스트 제공

## 레벨 디자인
- 스플라인 기반 경로(PathSplineActor)를 통해 적 이동 경로를 정의
- Portal 위치에서 웨이브 적이 스폰됨
- 맵/레벨 전환: 게임 오버 시 전용 GameOver 맵으로 이동

## UI 
- **UI**
    - 메인 HUD(골드/본진 HP/웨이브 시작/타워 건설 메뉴)
    - 타워 메뉴(판매/업그레이드)
    - 툴팁, 데미지 텍스트, 게임 오버 UI, 메인 메뉴

## 프로젝트 구조
```
TowerDefence/
├─ Config/                 # 프로젝트 설정
├─ Content/                # 에셋, 블루프린트, 데이터 테이블
├─ Source/
│  └─ TowerDefence/        # C++ 게임 로직
│     ├─ GamePlayGameMode  # 웨이브/경제/게임오버 처리
│     ├─ TDPlayerController# 입력/타워 배치 컨트롤
│     ├─ TowerBase         # 타워 공통 로직(공격/업그레이드/판매)
│     ├─ Enemy             # 적 이동/공격/체력
│     ├─ UI Widgets        # HUD/메뉴/툴팁
│     └─ PathSplineActor   # 경로 스플라인
└─ TowerDefence.uproject
```

## Blueprint 중심 / C++ 중심 여부
- **C++ 중심**: 핵심 게임 로직(웨이브/전투/경제/입력)이 C++로 작성
- **Blueprint 활용**: UI 위젯, 타워/적 BP, 데이터 테이블, 이펙트 등 콘텐츠 구성은 블루프린트/에셋에 의존
