# TowerDefence

### Unreal Engine 4.27 기반의 C++ 중심 타워 디펜스 게임
### 데이터 테이블 기반 웨이브 시스템과 스플라인 경로 AI를 구현한 전략 게임

## 프로젝트 개요
- **장르** : 타워 디펜스
- **목표** : 웨이브로 몰려오는 적을 처치하여 본진(타워) 체력을 지키는 전략 게임
- **플랫폼** : Unreal Engine 기반 PC 게임

## 아키텍처 개요
- 본 프로젝트는 1인 개발 프로젝트이지만, 실제 팀 단위 개발을 가정하여 시스템 간 역할 분리와 데이터 중심 설계를 목표로 구성
- 게임 규칙과 입력 처리, 데이터 설정을 분리하여 웨이브/타워/적 구성 변경 시 코드 수정 없이도 확장이 가능하도록 설계

## 프로젝트 기간
- 2025.06 ~ 2025.07

## 사용 엔진 버전
- Unreal Engine **4.27**

## 주요 기능 / 시스템
- **웨이브 시스템** : 데이터 테이블(`EnemyWaveData`)을 기반으로 적 스폰 수/간격, 체력, 이동 속도, 공격 주기 등을 설정하고 라운드를 진행
- **경제 시스템** : 골드 소비/획득, 웨이브 클리어 보상, 타워 건설 비용 관리
- **타워 배치/업그레이드/판매** : 타워 건설 미리보기와 배치 가능 영역 판정, 업그레이드/판매 UI 제공
- **타워 종류** : 기본 공격 타워, 스플래시 타워, CC(슬로우) 타워

## 캐릭터 컨트롤
- 캐릭터 이동 대신 **마우스 기반 컨트롤**을 사용
    - 좌클릭 : 타워 배치 확정/선택 해제
    - 우클릭 : 타워 선택/메뉴 토글, 배치 취소
- 배치 중에는 프리뷰 타워가 커서를 따라 이동하며, 충돌/경로 인접 여부로 배치 가능 여부를 표시

## 전투 / AI
- **적 AI** : 스플라인 경로를 따라 이동 후 본진에 도달하면 일정 주기로 공격
- **전투 로직** :
    - 타워는 일정 시간마다 가장 가까운 적을 탐색하고 공격
    - CC 타워는 적에게 슬로우를 부여
- **피드백** : 적 체력바 UI 및 피해 숫자 플로팅 텍스트 제공

## 시스템 책임 분리
### GameMode (웨이브 / 게임 흐름)
담당 역할:
- 웨이브 시작/종료 및 적 스폰 관리
- 게임 진행 상태(Game Over) 판정
- 골드 보상 지급

담당하지 않는 역할:
- 입력 처리
- 타워 배치 규칙 판단

### PlayerController (입력 / 배치 UX)
담당 역할:
- 마우스 입력 처리
- 타워 배치/선택/취소 상태 관리
- 배치 중 프리뷰 표시 및 배치 가능 여부 판단

분리 목적:
- 입력 처리와 게임 규칙 로직을 분리하여 흐름 추적과 디버깅 용이성 확보

### Tower 시스템
담당 역할:
- 일정 주기 타깃 탐색
- 공격 실행 및 피해/CC 적용
- 업그레이드/판매 처리

구조:
- TowerBase에 공통 공격 루프 구현
- 공격 방식은 파생 클래스에서 분리

### Enemy 시스템
담당 역할:
- 스플라인(PathSplineActor)을 따라 이동
- 피해 처리 및 본진 도달 시 공격

## 레벨 디자인
- 스플라인 기반 경로(PathSplineActor)를 통해 적 이동 경로를 정의
- Portal 위치에서 웨이브 적이 스폰됨
- 맵/레벨 전환: 게임 오버 시 전용 GameOver 맵으로 이동

## UI 
- **UI**
    - 메인 HUD(골드/본진 HP/웨이브 시작/타워 건설 메뉴)
    - 타워 메뉴(판매/업그레이드)
    - 툴팁, 데미지 텍스트, 게임 오버 UI, 메인 메뉴

## 프로젝트 구조
```
TowerDefence/
├─ Config/                 # 프로젝트 설정
├─ Content/                # 에셋, 블루프린트, 데이터 테이블
├─ Source/
│  └─ TowerDefence/        # C++ 게임 로직
│     ├─ GamePlayGameMode  # 웨이브/경제/게임오버 처리
│     ├─ TDPlayerController# 입력/타워 배치 컨트롤
│     ├─ TowerBase         # 타워 공통 로직(공격/업그레이드/판매)
│     ├─ Enemy             # 적 이동/공격/체력
│     ├─ UI Widgets        # HUD/메뉴/툴팁
│     └─ PathSplineActor   # 경로 스플라인
└─ TowerDefence.uproject
```

## 데이터 기반 설계
- 웨이브 구성 요소(적 수, 체력, 이동 속도, 스폰 간격)는 DataTable로 관리
- 코드 수정 없이 난이도 조정 및 웨이브 확장이 가능하도록 설계
- 스플라인 데이터 변경만으로 레벨 경로 수정 가능

## 설계 제약 조건
- 웨이브 로직은 특정 타워나 적 구현에 의존하지 않도록 구성
- 타워 공격 로직은 공통 인터페이스를 통해 확장 가능해야 함
- 경로 로직 수정이 적/타워 코드 변경으로 이어지지 않도록 분리

## 팀 개발을 가정했을 때 발생 가능한 문제점

- 타워 종류 증가 시 파생 클래스 수 증가 가능성  
→ 향후 개선 방향: 공격 로직을 컴포넌트 기반으로 분리

- 웨이브 데이터 증가 시 DataTable 관리 복잡도 증가  
→ 향후 개선 방향: 웨이브 그룹화 및 에디터 툴 지원

## C++ / Blueprint 사용 기준
- 웨이브, 전투, 경제, 입력 처리 등 핵심 게임 로직은 C++로 구현
- Blueprint는 UI 구성, 데이터 테이블, 이펙트 및 에디터 확장 용도로 사용
- 기획/레벨 수정 시 코드 변경을 최소화하는 것을 목표로 함
